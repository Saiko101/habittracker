# CLI Habit Tracker 
A minimalist terminal-based habit tracker built with Python and Questionary.

## How to Run
1. Clone the repository:
   ```bash
   git clone [https://github.com/YOUR_USERNAME/habittracker.git](https://github.com/YOUR_USERNAME/habittracker.git)
   cd habittracker

a. Install dependencies:
# Bash
pip install -r requirements.txt

b. Run app:
# Bash
python habittracker.py
